ANU & ADI — ROYAL FLORAL WEDDING INVITATION

Files:
- index.html  Main wedding invitation page
- style.css   Original design CSS plus responsive animation enhancements
- script.js   Countdown, mobile menu, gallery lightbox, wishes slider, scroll reveal, petals, parallax and RSVP logic

Run:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Internet is required for Google Fonts and the original reference photo URLs.

Before publishing:
1. In script.js, set CONFIG.whatsappNumber to the correct country-code + phone number (digits only).
2. Update the venue/address and event timings in index.html.
3. Replace the demo couple/gallery photographs with the actual couple photographs.
4. Update the story and parents' names to the real details.

The old Shopify tracking/pixel/WhatsApp widget scripts were intentionally excluded. The page now runs as a standalone HTML/CSS/vanilla-JS website.
